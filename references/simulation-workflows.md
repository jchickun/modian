# 模拟电路仿真流程

本页为工程补充，不声称复刻 AT 二维码或 Multisim 数字资源中的具体步骤。菜单、模型和求解器行为随软件版本而异。

1. **建模：** 核对电源、地、元件方向、晶体管/运放引脚顺序和模型范围；明确输入源内阻、负载与测量端口。
2. **直流工作点：** 先求静态工作点，检查各结电压、电流、器件区域和耗散，与手算 Q 点对比。收敛失败先检查浮置节点、反馈方向和供电。
3. **交流小信号：** 在有效 Q 点附近设置小信号源，扫频观察增益、相位和截止点。结果仅对应当前源阻抗、负载和偏置条件。
4. **瞬态：** 使用目标幅值和频率，观察削顶、压摆率、振荡启动、过冲和稳定时间；步长应解析最快边沿，仿真时长覆盖最慢时间常数。
5. **参数扫描：** 改变供电、负载、温度和关键元件容差，记录扫描范围、初始条件、模型和工具版本。
6. **交叉核验：** 每类分析至少挑选一个可手算工作点。仿真只验证所用模型与条件，不自动覆盖 PCB 寄生、器件离散、热设计或可靠性。
