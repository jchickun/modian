# A03 原题重构：AP 例 3.3.7–3.3.9

**来源：** AP《模拟电子技术基础学习辅导与习题解答（第六版）》例 3.3.7–3.3.9，印刷 pp.106–109 / PDF pp.115–118。页图、答案序列及规格概念边界逐项复核见[AP A03 例题 3.3.5–3.3.9 审计](../sources/a03-ap-examples-5-9-audit.md)。依据原页的题目、答案和解析归纳，不复制原书整段题干；本组为运放组成、参数含义与选型判断题。

## 例 3.3.7：从性能要求判断运放各级结构

原题 9 项选择题答案为 **(1) C，(2) B，(3) C，(4) A，(5) A，(6) B，(7) C，(8) C，(9) B**。

| 项 | 选择结论 | 判据 |
|---|---|---|
| (1) 集成运放采用直接耦合 | 芯片难以制造足够大的电容 | 芯片面积有限；直接耦合并非为了增益更大或温漂更小。 |
| (2) 通用型运放适用频段 | 低频 | 芯片内部结电容和分布电容限制高频响应；“通用型”不代表任意频率都适用。 |
| (3) 同类半导体管参数 | 一致性较好 | 邻近器件制造与温度环境相近；这不意味着参数绝对准确或不随温度变化。 |
| (4) 输入级采用差分放大 | 减小温漂 | 差分结构抑制共模漂移；不能据此推断差模增益或输入电阻必然很大。 |
| (5) 双极型运放中间级 | 共射 | 共射适合提供主要电压增益；共集电压增益近 1，共基输入电阻低。 |
| (6) 使用有源负载 | 增大电压增益 | 电流源负载提供较大的交流等效电阻；实际增益仍受有限 `r_o` 限制。 |
| (7) 输出级 | 互补输出级（OCL） | 兼顾负载驱动、较大不失真摆幅和较低静态功耗。 |
| (8) 设置静态工作点 | 电流源提供稳定的集电极或发射极电流 | 集成运放通常用电流源支路偏置各级。 |
| (9) 运放外部等效结构 | 双端输入、单端输出差分放大电路 | 两个输入端均不直接接地，外部只有一个输出端。 |

**迁移方法：** 先把性能要求映射到输入级、中间级、输出级或偏置网络，再选择结构；不要把“直接耦合”“差分输入”“有源负载”等结构分别误解成增益、温漂、输入电阻等所有指标都同时改善。

## 例 3.3.8：运放参数物理意义判断

原题判断结果为 **(1) √，(2) √，(3) ×，(4) √，(5) √，(6) ×，(7) √，(8) ×**。

| 项 | 结论 | 核验要点 |
|---|---|---|
| (1) 开环差模增益 | √ | 描述无反馈时，输出对两输入端差模电压的放大能力。 |
| (2) 差模输入电阻 | √ | 按两输入端之间的差模端口定义等效电阻。 |
| (3) 输入失调电压 `U_I0` | × | 它是使输出回到零值所需的等效输入补偿电压，不是两输入端电位差本身的定义。 |
| (4) 输入失调电流 `I_I0` | √ | 两输入端静态偏置电流之差的绝对值。 |
| (5) 共模抑制比 | √ | 按 AP 记号 `K_CMR=|A_od/A_oc|`，即差模增益与共模增益之比。 |
| (6) 最大共模输入电压 | × | AP 将其定义为输入级仍能正常放大差模信号时可施加的最大共模输入；题干说成“避免损坏的最大电压”，混淆了正常工作范围与绝对最大额定值。 |
| (7) 最大差模输入电压 | √ | 按题目所用指标，指输入端间可承受而不损坏输入级的最大差模电压；实际使用仍须查具体器件数据手册。 |
| (8) 转换速率 `SR` | × | 它是在大信号条件下输出电压的最大变化率，`SR=max|du_o/dt|`；不是输入交流信号下输出交流量的“最大值”。 |

特别注意第 (6)、(7) 项的规格语境：**正常线性工作范围**和**不损坏的绝对最大额定值**是两类不同限制，不能互换。AP 的判断是针对教材列出的参数定义；具体型号还应查数据手册的定义与测试条件。

## 例 3.3.9：按信号与负载选择运放类型

题目给定类型：①通用型、②高阻型、③高速型、④低功耗型、⑤高精度型、⑥高压型、⑦大功率型。原题条件与选择如下。

| 应用要求 | 选型 | 理由 |
|---|---|---|
| 放大缓慢变化的直流信号 | ① 通用型 | 无特殊速度、精度或功耗要求时，按题设优先选通用型。 |
| 放大 10–100 MHz 交流信号 | ③ 高速型 | 先满足带宽与高速响应，再核对增益、稳定性和负载。 |
| 微弱信号前置放大 | ⑤ 高精度型 | 优先关注失调、漂移和噪声等误差指标。 |
| 放大高内阻传感器的输出 | ② 高阻型 | 高输入电阻可减小对传感器的加载。 |
| 使扬声器得到 5 W 音频功率 | ⑦ 大功率型 | 重点是负载电流、输出功率与散热能力。 |
| 输出电压范围约 0–+50 V | ⑥ 高压型 | 需满足供电电压、共模范围与输出摆幅。 |
| 遥控器中的放大器 | ④ 低功耗型 | 以降低电源消耗为主要目标。 |

原题顺序答案为 **①、③、⑤、②、⑦、⑥、④**。这是一道按“首要约束”选型的教材题；实际设计不能只按类别名选型，还需逐项核查供电、输入共模范围、输出摆幅/电流、噪声、带宽、稳定性、功耗和热限制。
