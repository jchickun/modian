## 通用解题流程

### 运算电路

1. 标出每一级运放的输入端、输出、反馈路径和参考地；有乘法器、积分器等有源块时，先用瞬时极性法确认该环路对该级运放形成负反馈。
2. 确认线性工作假设成立后，写 `u_+=u_-` 与输入电流约为零；若结果越过电源轨或输入共模范围，改判饱和，不能保留虚短结果。
3. 先列关键节点 KCL。多输入时可对其余理想电压源置零逐支路叠加；多级时由前级输出逐级代入，同时保留每级初始状态。
4. 检查符号、单位、极性/象限、输入动态范围和输出摆幅。积分题明确 `u_o(t₀)`；除法/开方题先列定义域和反馈符号。

### 滤波电路

1. 先确认运放负反馈和有效动态元件，再用 `s=jω` 写传递函数；避免仅凭“电容在输入/反馈上”猜类型。
2. 比较 `ω→0` 与 `ω→∞` 的增益：`通—阻`为低通、`阻—通`为高通、`阻—阻`为带通、`通—通而中段衰减`为带阻。
3. 从分母确定极点/阶数，再求通带增益、特征频率、`Q`、带宽或题目定义的截止点。−3 dB 必须相对于通带增益测量；有纹波时以题目给定的通带/阻带规格为准。
4. 若级联无缓冲 RC 网络，先考虑相互加载；若是有源滤波，检查运放增益带宽、稳定性、输入共模及输出余量。

### 先确认运算电路满足虚短/虚断条件

1. 找出从输出回到运放输入的完整反馈环；复合电路中乘法器、积分器或其他运算块也属于环路的一部分。
2. 对相关输入施加一个小的正扰动，沿整环追踪输出及反馈量的方向；若反馈使差模输入 `u_+−u_-` 朝零变化，才是负反馈。输入极性、乘积系数 `k` 或工作状态变化后要重判。
3. 只有负反馈且运放处于稳定线性区时，才使用 `u_+≈u_-`、`i_+≈i_-≈0`。若输出越轨、环路成为正反馈或积分状态不明，应改用饱和/动态状态分析。
4. 分别列节点 KCL；多源线性网络可用叠加，多级理想运算电路可逐级代入。实物级联还要查后级负载、输出电流、摆幅、带宽和容性负载稳定性。

### 滤波器先看两个频率极限

1. 在理想 RC 近似下，先分别求 `f→0`（电容开路）和 `f→∞`（电容短路）时的输出/输入增益；再查中间频带是否有通带或陷波。
2. 低频通、高频阻为 LPF；低频阻、高频通为 HPF；两端阻、中间通为 BPF；两端通、中段阻为 BEF。复合滤波器要看整个传函或整体幅频，不能只按单个 RC 支路命名。
3. 串联 HPF 与 LPF 构成带通时，HPF 截止应低于 LPF 截止；并联/求和构成带阻时，LPF 截止应低于 HPF 截止。检查级间加载、相加的增益/相位和缓冲后再定截止点。
4. 从完整分母读极点、阶数和 `Q`，再以通带或峰值为基准求 −3 dB 点。AP 图 6.2.4(a) 的二阶带通中心峰值是 `KQ`，其中 `K` 为运放闭环增益；不能把 `K` 直接当成滤波器峰值。

### 运算精度快速排查

先给理想解做符号、单位、动态范围和饱和检查，再按拓扑找主导误差：反相比例级查有限开环增益/输入电阻、失调与偏置电流；同相级额外查共模输入和 CMRR；积分器重点查失调及其漂移；滤波器查 R/C 误差、运放 GBW、输出余量和稳定性。误差预算要针对实际连接，不能只换更精密的电阻就认为精度问题已解决。

## 题型转换与快速核验

- **未知运算关系：**每一级独立列节点方程，写出中间输出，再代入；对有源反馈块先判符号。结果反号时回看输入端接法与乘积系数，不要在末尾靠“补一个负号”修正。
- **给目标表达式设计电路：**按运算顺序拆成比例、求和、积分、乘法/开方等基本块；先选电路，再按系数求电阻比或 `RC`，最后安排同相端补偿电阻并估算元件误差。
- **积分波形：**将时间轴按输入跃变分段；反相积分器每段用 `Δu_o=−(u_i/RC)Δt` 更新输出，并把上段终值当作下段初值。先查看输入是否有直接通路：AP P6.12 的非反相结构在输入阶跃时 `Δu_o=Δu_i`，其余区间再按 `u_i/(RC)` 更新；不得把它按纯反相积分器画成连续输出。
- **微分波形：**检查每个边沿方向和斜率；实际微分器要以有限带宽模型判断尖峰，不能把理想冲激当成可实现电压。
- **乘/除/开方：**写出乘积公式并保留 `k` 单位；先验算输入象限/定义域，再看闭环极性、过零点和饱和边界。
- **滤波识别：**代入 `s=0` 和 `s→∞` 看极限；再数参与频率响应的极点并列 KCL。低通截止频率不能代替中心频率或 `Q`。
- **预处理电路：**从传感器类型出发选择电压/电荷/差分/隔离结构，给定信号幅值、源阻抗、共模范围、目标带宽和 ADC 满量程，再分配增益与滤波。

## 常见错误

- 把虚地当成实际接地，误认为信号源可忽略输出电流。
- 理想积分器漏掉初始值；或忽略反馈泄放电阻造成的低频行为变化。
- 把理想微分器用于高频实际信号，不限制噪声增益与相位裕度。
- 未判断有源反馈极性便套虚短；乘法器的 `k` 或输入极性变化后仍沿用原公式。
- 将特征频率、通带截止点与 −3 dB 点混为一谈；忽略负载与级间加载。
- 仪表放大器只看差模增益，不核共模范围、CMRR 和电阻比匹配；电荷放大器忽略传感器电缆电容与低频泄放极点。

## AT 思考题 6.1.1–6.1.6：运算电路识别、设计与波形

**原题位置：** 印刷 p.275 / PDF p.307；题干见[AT §6.1.7–§6.2.2 页图审计](../sources/a06-at-pages-273-278-audit.md)。图 6.1.7 在印刷 p.261/PDF p.293，图 6.1.26 在印刷 p.270/PDF p.302；图页和器件关系分别见[加减/积分/微分审计](../sources/a06-at-pages-261-266-audit.md)与[逆运算/PID/对数指数审计](../sources/a06-at-pages-267-272-audit.md)。原书仅列题干，无可见答案。

1. **识别运算电路并判断级间影响（6.1.1）：** 看运放周围的反馈元件和传递关系是否实现比例、求和/差、积分、微分、对数等规定的数学运算；先判环路为负反馈且运放未饱和，再用虚短、虚断和 KCL 求 `u_o(u_i)`。理想模型下运放输入电阻无穷大、输出电阻为零，前级不被后级取电流，级联可逐级求解；实际运放输入电流、输出电阻、有限带宽、摆幅及负载会产生级间误差，不能把理想隔离当成实物保证。
2. **分析输入—输出运算关系（6.1.2）：** 为每级标出 `u_+`、`u_-`、输出和反馈支路，画直流/交流等效通路；先根据反馈极性确认线性工作假设，再用 `u_+≈u_-`、输入电流约为零、KCL 和元件关系逐级列式。积分电路保留初值项，微分/积分的相位和符号由端口极性确定；最后检查量纲、初值、频率范围、共模范围和输出饱和，必要时分段改用饱和模型。
3. **图 6.1.7 各信号源看到的输入电阻（6.1.3）：** 该图是反相求和器，理想线性条件下反相端为虚地，各信号源分别经各自输入电阻到虚地，所以 `R_in,1=R_1`、`R_in,2=R_2`、`R_in,3=R_3`。每个源看到的是自己的支路输入电阻，不是三个电阻并联；反馈电阻 `R_4` 接输出与求和节点，不改变各源到虚地的独立通路。实际值还受运放输入阻抗、源阻抗和频率影响。
4. **实现 `u_o=k_1u_1−k_2u_2` 且两源输出电流为零（6.1.4）：** 一个可行方案是先分别用电压跟随器缓冲 `u_1`、`u_2`，理想输入端不取源电流；再分别构造 `v_1=−k_1u_1` 与 `v_2=+k_2u_2`，最后用单位增益反相求和器得 `u_o=−(v_1+v_2)=k_1u_1−k_2u_2`。两路正增益可由非反相级实现，负号路由反相级实现；若某系数小于 1，可在缓冲后分压，若大于 1 用相应增益级。实际电路需计入偏置电流、失调、阻值误差和输出摆幅。
5. **方波输入积分器及初值影响（6.1.5）：** 理想反相积分器满足 `du_o/dt=−u_i/(RC)`。若输入以 `+U_{1m}` 开始、每半周期翻转，周期为 `T`，则第一半周输出斜率为 `−U_{1m}/(RC)`，变化量 `−U_{1m}T/(2RC)`；第二半周斜率反向，输出返回原值，形成三角波。初值 `u_o(0)=0` 时理想波形在 `0` 与 `−U_{1m}T/(2RC)` 间变化；非零初值只把整条波形竖直平移 `u_o(0)`，不改变斜率和峰峰值。若方波先从负半周开始，斜率顺序相反；真实积分器的失调、泄漏和输出限幅会造成漂移或削顶。
6. **负输入的集成对数电路改接（6.1.6）：** 图 6.1.26 用匹配 PNP 对，原参考支路按正输入电流方向工作。`u_i<0` 时，`R_3` 支路电流方向反转，原 PN 结的正向导通条件不再成立。应改用匹配 NPN 对，并按新管型反接参考/偏置电流支路，使两只结仍在正向指数区；从 `|u_i|/R_3` 建立新的对数关系，再按新的 `u_{BE}` 参考方向重推输出极性和偏置。不可把负数直接代入 `ln(u_i)`，也不可只反接 `U_REF` 而让原晶体管结反偏。

## AT 思考题 6.2.1–6.2.3：平方、逆函数反馈与除法器

**原题位置：** 印刷 p.283 / PDF p.315；题干、例 6.2.1 与图 6.2.14 见[AT §6.2.2–§6.3.1 页图审计](../sources/a06-at-pages-279-284-audit.md)。原书仅列题干，无可见答案。

1. **提取正弦的二倍频交流分量（6.2.1）：** 将 `u_i=U_m cos(ωt)` 输入平方乘法器 `u_s=ku_i²`，得 `u_s=(kU_m²/2)[1+cos(2ωt)]`。用隔直电容/交流耦合高通去掉直流分量，令其截止频率远低于 `2f`，即可保留二倍频正弦；负的乘积系数只改变交流分量的相位符号。真实乘法器的偏置、失真和带宽会带来额外残留，后级需留出幅度余量。
2. **逆函数负反馈原理（6.2.2）：** 将非线性函数块 `y=f(x)` 放入运放负反馈环路，使参考输入 `r` 与反馈量 `f(x)` 的误差趋近于零，于是 `f(x)≈r`，在 `f` 单值、可逆且处于有效范围时得到 `x≈f^{-1}(r)`。设计时先确认反馈符号能使误差减小，再列运放节点方程和非线性块关系；函数的定义域/值域、多个数学分支、启动状态、稳定性与输出饱和都可能使理想反函数解不可实现。
3. **乘法器实现除法及极性组合（6.2.3）：** 令乘法器输出 `u_m=ku_ou_D`，将其经必要的反相器/极性选择块送到运放反相端，把被除数 `u_N` 经必要的极性校正送到同相端。结构关系如下，`σ_f`、`σ_N` 对应直接接入或反相：

   ```mermaid
   flowchart LR
     UO[u_o] --> M[乘法器 ×k]
     UD[u_D] --> M
     M --> SF[极性校正 σ_f] --> MINUS[运放反相端 −]
     UN[u_N] --> SN[极性校正 σ_N] --> PLUS[运放同相端 +]
     MINUS --> A[运放]
     PLUS --> A
     A --> UO
   ```

   记两路校正符号为 `σ_f,σ_N∈{+1,−1}`，线性平衡时 `σ_Nu_N=σ_fk u_ou_D`，故 `u_o=(σ_N/σ_f)u_N/(ku_D)`。为使输出上升时反相端反馈电压也上升、形成负反馈，取 `σ_f=sgn(ku_D)`；同时取 `σ_N=σ_f`，使目标关系保持 `u_o=u_N/(ku_D)`。因此：

   | 乘积系数 `k` | 除数 `u_D` | 反馈乘积极性 `σ_f` | 被除数极性 `σ_N` |
   |---|---:|---|---|
   | 正 | 正 | 直接接入 `+1` | 直接接入 `+1` |
   | 正 | 负 | 反相 `−1` | 反相 `−1` |
   | 负 | 正 | 反相 `−1` | 反相 `−1` |
   | 负 | 负 | 直接接入 `+1` | 直接接入 `+1` |

   `u_N` 自身可正可负，决定输出符号，但不改变反馈环路的稳定极性。`u_D=0` 时除法无定义，接近零时理想输出会很大，实际会受乘法器输入范围、运放共模/摆幅和输出限幅约束；选好 `σ_f` 后仍须用实际电路逐环确认反馈方向。

## AT 思考题 6.3.1–6.3.3：有源滤波器与积分器用途

**原题位置：** 印刷 p.297 / PDF p.329；题干见[AT §6.3.4–§6.3.5 入口页图审计](../sources/a06-at-pages-296-297-audit.md)和[AT §6.4 页图审计](../sources/a06-at-pages-297-302-audit.md)。两节二维码只给扩展标题，未取得正文；以下只解释可见题干，未将外部扩展内容冒充教材答案。

1. **识别有源滤波器并比较运算电路（6.3.1）：** 检查电路是否包含运放等有源器件和形成频率选择性的 R/C 网络；写出 `H(s)=U_o(s)/U_i(s)`，看其极点、零点及 `|H(jω)|` 是否随频率改变并满足滤波目的。它与运算电路一样使用有源器件、反馈和 R/C 元件，且运算电路也可能具有频率响应；区别在于运算电路主要实现时域数学关系，滤波器主要按频率选择/抑制信号分量。积分器本身既可视作运算电路，也可在指定频带内作为低通功能块。
2. **判定 LPF/HPF/BPF/BEF 与阶数（6.3.2）：** 先约去传递函数中真正可约的公共因子，再检查低频和高频极限，并结合幅频曲线判断通带位置：低频通过为 LPF，高频通过为 HPF，仅中间频段通过为 BPF，某一中间频段被抑制为 BEF。阶数按约简后分母多项式的次数（等价于极点数，按重数计）确定；不能按元件数或电路图中的 RC 对数直接计数。若有极零相消，应确认是精确相消还是仅近似；实际运放有限带宽可能增加高频极点，使实测响应偏离理想阶数模型。
3. **积分器的其他用途（6.3.3）：** 积分器可把方波变三角波、生成斜坡/扫描波、保存模拟状态变量、作为有源滤波器/状态变量滤波器的积分环节、实现模拟微分方程求解器，并作为 PI/PID 控制器的积分支路。上述功能需要与输入、反馈、限幅或其他积分级组成相应系统；单独一个积分器不自动成为振荡器，实际还要检查直流偏置累积、复位方式、初始条件和输出摆幅。

## AT 思考题 6.4.1–6.4.2：传感器接口与抗干扰

**原题位置：** 印刷 p.302 / PDF p.334；题干、噪声公式和图表见 [AT §6.4 页图审计](../sources/a06-at-pages-297-302-audit.md)。AT PDF 没有提供这两题的答案；以下是按前文模型整理的解题路线。

1. **比较三类放大器：** 仪表放大器放大微小差分电压，同时保持高输入阻抗和较高共模抑制，适合电桥、热电偶等带共模电压的低电平传感器；电荷放大器将高阻电容传感器输出的电荷转换为电压，理想关系 `u_o=−q/C_f`，适合压电加速度/压力传感器，并用 `R_fC_f` 决定低频泄放边界；隔离放大器在输入、输出间切断直流导电通路，适合地电位不同、地环路或高共模干扰场合。分别补充实际输入/共模范围、低频截止和隔离额定值。
2. **干扰与噪声来源及抑制：** 将外部干扰（高压电网、电焊机、无线发射、雷电）与器件噪声（电阻/半导体热噪声、PN 结散弹噪声、半导体 `1/f` 噪声）分开。先按电源传导、磁耦合、电场/寄生电容耦合定位路径，再选择远离干扰源、屏蔽/布线隔离、供电去耦/滤波、针对已知频带的有源滤波、低噪声器件和合适电阻值。采样平均只适用于独立随机噪声，不能消除偏置、混叠或相干干扰；滤波也不能替代输入共模、地线和动态范围设计。
