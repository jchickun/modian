# A04 配套原题：AP 例 4.3.4

来源：AP 印刷 140–142 页 / PDF 149–151，图 4.3.4–4.3.6；已回原图核对。配套：[知识](a04-frequency-knowledge.md) · [练习](a04-frequency-practice.md)。

## 连接、条件与参数

发射极接地的共射级；信号源经 R_s、耦合电容 C 到基极，R_b 从电源接基极，集电极经 R_c 接电源，输出取集电极。按原题已给的 Q 点进行小信号分析，不另用偏置网络重新假定 I_CQ。

| 参数 | 原题数值 |
|---|---:|
| β | 100 |
| r_bb' / Ω | 100 |
| I_CQ / mA | 1 |
| R_s / kΩ | 1 |
| R_b / kΩ | 600 |
| R_c / kΩ | 5 |
| C / μF | 1 |
| C_μ / pF | 5 |
| f_β / kHz | 400 |

热电压采用书中的 26 mV（V_T）；此处 β 用作 Q 点的小信号电流增益；忽略输出电阻并采用原书单输入主导极点、米勒近似。f_β 是共射电流增益截止频率，不能当作 f_T。

## 从电容的端口求解

r_b'e=βV_T/I_CQ=2.6 kΩ，r_be=r_bb'+r_b'e=2.7 kΩ。R_b 远大于 r_be，原书取 R_i≈r_be；基极到输出增益约 −βR_c/r_be，信号源到输出增益还要乘 R_i/(R_s+R_i)。

低频时 C_π' 开路，耦合电容两端看到的电阻是 R_s+(R_b∥r_be)，书中近似为 R_s+r_be。高频时耦合电容短路，米勒等效电容位于内部基极 b'，它看到 r_b'e∥[r_bb'+(R_b∥R_s)]，不能用外部基极的 r_be 替代。

C_π=1/(2πr_b'e f_β)−C_μ；g_m=I_CQ/V_T；C_π'=C_π+(1+g_mR_c)C_μ。原书将 R_b 视为远大于其他相关电阻并适当取整，得到：

| 结果 | 原书近似值 |
|---|---:|
| 基极到输出中频增益 | -185 |
| 信号源到输出中频增益 | -135 |
| 低频电容所见电阻 / kΩ | 3.7 |
| f_L / Hz | 43 |
| C_π / pF | 148 |
| C_π' / pF | 1116 |
| 高频电容所见电阻 / Ω | 773 |
| f_H / kHz | 184 |

以上是原书近似层级的结果；保留有限 R_b 或更多有效位会有小差别，不把取整后的数值当精确器件保证值。

信号源到输出可近似写 H(f)=A_sm·(jf/f_L)/[(1+jf/f_L)(1+jf/f_H)]，A_sm≈−135。中频约 43 dB，低频幅度渐近斜率 +20 dB/十倍频，高频为 −20 dB/十倍频；反相中频相位可写 −180°，不要遗漏反相符号。

## 迁移检查

改变 R_s 会同时改变输入分压、低频时间常数和高频等效电阻；增益和带宽须一起重算。若增加集电极负载，还会改变增益及米勒电容。这些属于基于本题的变式分析，不是原题的附加问答。若高频输出极点不再远离输入极点，应回完整高频等效电路求解。
