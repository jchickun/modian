# A06 原书例题重构

**来源：**《模拟电子技术基础学习辅导与习题解答（第六版）》第 6 章。以下只重构列出的原题，不替代整章题解。图号、印刷页和 PDF 页同时给出，以便回看原图。

## AP 例 6.3.1：两种差分放大电路的识别与分析

**原书位置：**图 6.3.1(a)(b)，印刷 pp.210–212 / PDF pp.219–221。理想运放条件下，先分级识别电路，再用叠加或节点 KCL 求差模关系。

- **(a) 同相级与差值级：**`u_o1=(1+R_3/R_1)u_i1`。第二级对两输入叠加为
  `u_o=−(R_5/R_4)u_o1+(1+R_5/R_4)u_i2`。
  使用图示匹配 `R_3/R_1=R_4/R_5` 后，`u_o=(1+R_5/R_4)(u_i2−u_i1)`。
- **(b) 三运放差分结构：**首级差分增益为 `u_o1−u_o2=(1+2R_1/R_2)(u_i1−u_i2)`，末级差值放大器给
  `u_o=−(R_f/R)(1+2R_1/R_2)(u_i1−u_i2)`。
- 两图都是双端输入、单端输出的差分放大电路。理想模型下，两个输入都进非反相端，运放输入电流为零，所以两电路的输入电阻均为无穷大；实物输入偏置电流和源阻抗使该结论仅为理想近似。

完整端口与电阻比核对见[例 6.3.1–6.3.3 页图审计](../sources/a06-ap-examples-1-3-audit.md)。

## AP 例 6.3.2：积分器输入方波与输出分段更新

**原书位置：**图 6.3.2(a)、输入波形图 6.3.2(c)，印刷 pp.212–213 / PDF pp.221–222。参数 `R=100 kΩ`、`C=0.1 μF`，故 `1/(RC)=100 s⁻¹`；理想积分器初值为 `u_o(0)=0`。

输入按图分为四段：`0–5 ms: +5 V`、`5–15 ms: −5 V`、`15–25 ms: +5 V`、`25–35 ms: −5 V`。每段斜率 `du_o/dt=−u_i/(RC)`：

| 时刻 | 分段计算 | 输出 |
|---|---|---:|
| `0 ms` | 初始值 | `0 V` |
| `5 ms` | `−100×5×5 ms` | `−2.5 V` |
| `15 ms` | 从 `−2.5 V` 加上 `−100×(−5)×10 ms` | `+2.5 V` |
| `25 ms` | 从 `+2.5 V` 加上 `−100×5×10 ms` | `−2.5 V` |
| `35 ms` | 从 `−2.5 V` 加上 `−100×(−5)×10 ms` | `+2.5 V` |

因此输出在各区间线性变化，并在输入反相时反转斜率。正确作图的关键是每段沿用上一段终值；只由“方波积分为三角波”无法确定绝对电平。

## AP 例 6.3.3：积分反馈实现微分

**原书位置：**图 6.3.4–6.3.5，印刷 pp.213–214 / PDF pp.222–223。A1 为反相加法器，输入 `u_i` 与积分器输出 `u_o2` 进入反相虚地节点：

`u_i/R_1+u_o2/R_2=0`，所以 `u_o2=−(R_2/R_1)u_i`。

A2 为以 `u_o` 为输入的反相积分器：

`u_o2=−1/(R_3C)∫u_o dt`，即 `u_o=−R_3C·du_o2/dt`。

代入得

`u_o=(R_2R_3C/R_1)·du_i/dt`。

这是将积分器置于负反馈环中实现的微分关系。两级都须保持负反馈和线性工作；真实带宽、稳定性、噪声、输出摆幅及积分初始状态仍受器件与闭环条件限制。原书极性和系数经节点方程复算一致，见[专项审计](../sources/a06-ap-examples-1-3-audit.md)。

## AP 例 6.3.4：对数—求和—指数实现乘除

**原书位置：**图 6.3.6、6.3.7，印刷 pp.214–215 / PDF pp.223–224。A1、A2 以晶体管反馈构成对数级，A3 为反相求和级，T3 与 A4 构成指数级。匹配晶体管、等权求和时，对数输出相加再指数还原，整体实现 `u_o∝u_i1u_i2`。要实现 `u_i1/u_i2`，将 A3 改为差分比例级，使其对两个对数输出作差，再由指数级还原。

该原题考查级联运算识别和负反馈极性。对数级要求两个输入为正且晶体管处于正向有源范围；实际动态范围、匹配、温漂、失调和饱和都会限制乘除精度。教材未给完整标定常数，故这里只给运算关系，不虚构数值比例系数。逐级关系、除法改法和来源边界见[例 6.3.4 页图审计](../sources/a06-ap-examples-4-5b-audit.md)。

## AP 例 6.3.5(a)：乘法器反馈除法

**原书位置：**图 6.3.8(a)，印刷 p.216 / PDF p.225。原题设理想运放、理想乘法器，乘积系数 `k>0`，第三输入 `u_i3>0`。

两个运放输入端为虚地，求和点满足：

`u_i1/R₁ + u_i2/R₂ + u'_o/R₃ = 0`，且 `u'_o=k u_i3 u_o`。

从而

`u_o=−R₃(u_i1/R₁+u_i2/R₂)/(k u_i3)`。

反馈方向可作瞬时极性核验：`u_o` 增大使 `u'_o` 同向增大；`u'_o` 经 `R₃` 注入反相求和点，促使运放输出回落，故在题设 `k u_i3>0` 时为负反馈。`u_i3=0` 不可用；`u_i3` 变号会改变环路极性，必须重新接线/论证，不能把上式不加条件外推。

图 6.3.8(b) 的平方和开方组合题由两个前级平方器、反相求和和末级平方反馈构成，完整关系见下方例 6.3.5(b)；其反馈原理也见[乘法器深入页](a06-multiplier-filter.md)。

## AP 例 6.3.5(b)：乘法器实现平方和开方

**原书位置：**图 6.3.8(b)，印刷 pp.216–217 / PDF pp.225–226。前两个乘法器把信号平方：`u_o1=k u_i1²`、`u_o2=k u_i2²`。`R_1=R_2=R_4` 时，A1 反相求和得 `u_o3=−k(u_i1²+u_i2²)`；`R_5=R_6` 的 A2 反相级使 `u_o4=−u_o3`。末级乘法器的两个输入都接 `u_o`，故 `u_o4=k u_o²`，联立得到

`u_o=√(u_i1²+u_i2²)`。

该结果取闭环选定的非负根，且建立在理想乘法器、题设等值电阻和运放线性负反馈成立的条件下。`k` 的单位为 `V⁻¹`，因此 `k u_i²` 的量纲为电压；实际要核验乘法器输入范围、运放输出余量和平方根闭环稳定性。节点方程及原页核对见[专项审计](../sources/a06-ap-examples-4-5b-audit.md)。

## AP 例 6.3.6：除法电路随除数极性切换输入端

**原书位置：**图 6.3.9 与解图 6.3.10，印刷 pp.217–218 / PDF pp.226–227。原题 `k=0.1 V⁻¹`，图中电阻使同相放大系数 `1+R_f/R=3`。

当分母输入 `u_i2>0` 时，题图接法使乘法器输出作为正反馈电压返回后能形成负反馈；当 `u_i2<0` 时，为保持负反馈须交换运放的同相、反相输入端接法。错误接法会形成正反馈，虚短分析失效，输出趋于饱和。

正确接法下，虚短给出乘法器输出 `u'_o=k u_i2 u_o=(1+R_f/R)u_i1`，因此：

`u_o=(1+R_f/R)u_i1/(k u_i2)=30u_i1/u_i2`。

结果是两种除数极性下的理想运算式相同，但电路接线不同。该式仍要求 `u_i2≠0`、输出未饱和，并满足乘法器与运放的电压范围。

## AP 例 6.3.7：按目标运算选择基本电路

**原书位置：**印刷 p.219 / PDF p.228。原页定义 A–J 为反相比例、同相比例、差分比例、积分、微分、反相求和、同相求和、平方乘法、加减运算和电压跟随。原解 12 小题答案依次为 `D、H、G、A、D、E、B、J、E、G、I、H`；第 (2) 题平方产生二倍频，第 (5)(6)(9) 题分别用积分方波、微分方波和微分三角波完成波形变换。

第 (1) 题原题写正弦波移相 `+90°`，原解给 D（积分）。按通常相量约定，积分器相移 `−90°`，微分器相移 `+90°`，故该题若正负号按输出相位减输入相位定义应选 E。原书未声明移相正负约定，保留为来源差异；完整判断与其他 11 题映射见[例 6.3.7 审计](../sources/a06-ap-examples-7-9-audit.md)。

## AP 例 6.3.8：积分与比例信号的加权合成

**原书位置：**图 6.3.11，印刷 pp.219–220 / PDF pp.228–229。目标 `u_o=100∫u_i1dt+10u_i2`。方案 (a) 用反相积分器 `u_o1=−1/(RC)∫u_i1dt`，再由差分级实现 `u_o=−(R_f/R_1)u_o1+(R_f/R_1)u_i2`。取 `R_f/R_1=10`，`C=2 μF`，则 `1/(RC)=10 s⁻¹`，得 `R=50 kΩ`；原解 `R_1=10 kΩ`、`R_f=100 kΩ` 满足 `100 kΩ` 电阻上限。

图 6.3.11(b)(c) 是其他可行结构，参数需要按各自级联增益和积分常数重新求解；不存在唯一拓扑。原页推导和参数复算见[例 6.3.8 审计](../sources/a06-ap-examples-7-9-audit.md)。

## AP 例 6.3.9：平方积分后开方

**原书位置：**图 6.3.12，印刷 pp.221–222 / PDF pp.230–231。目标 `u_o=√(a∫u_i²dt)`。乘法器先给 `u_o1=k u_i²`；反相积分器得到 `u_o2=−k/(R_1C)∫u_i²dt`；末级平方反馈的乘法器—运放开方环满足 `u_o3=−(R_4/R_3)u_o2=k u_o²`。选定非负闭环支路后：

`u_o=√[R_4/(R_1R_3C)∫u_i²dt]`，`a=R_4/(R_1R_3C)`。

`a` 的单位为 `s⁻¹`，使根号内为 `V²`。积分初值、负反馈极性、输入平方范围和饱和边界均须核查；原书式对应零初始状态。详细 KCL 与量纲审计见[例 6.3.9 审计](../sources/a06-ap-examples-7-9-audit.md)。

## AP 例 6.3.10：按目标频段选择有源滤波器

**原书位置：**印刷 p.222 / PDF p.231。选项为高通、低通、带通、带阻。原解依次为：50 Hz 工频干扰用带阻；1–2 kHz 信号拒绝带外干扰用带通；提取低频用低通；提取高频用高通；低频端响应为零选高通或带通；高频端响应为零选低通或带通；两端响应均为零选带通；两端响应均保留而中间衰减选带阻。

这些只识别滤波器类别，具体阶数、Q、截止频率和阻带衰减须按频谱指标另行设计。原图和答案核对见[例 6.3.10–6.3.11 审计](../sources/a06-ap-examples-10-11-audit.md)。

## AP 例 6.3.11：有源与无源滤波器的边界

**原书位置：**印刷 pp.222–223 / PDF pp.231–232。五项原解为 `√、√、×、×、√`：无源网络的负载会改变其滤波特性；理想有源滤波器输出电阻趋小；通带对负载较不敏感不等于能驱动电源的大电流；无源滤波器也可处理信号；适当的运放反馈网络可实现“积分器在反馈中构成微分关系”或“低通反馈实现高通”的逆运算。

理想输出电阻为零只是模型结论。实际有源滤波器仍受运放频宽、相位裕度、负载电流、输出摆幅和稳定性限制；具体反馈拓扑应重新推导传递函数。逐项判据见[专项审计](../sources/a06-ap-examples-10-11-audit.md)。

## AP 例 6.3.12：三种有源滤波器通带识别

**原书位置：**图 6.3.13(a)–(c)，印刷 pp.224–225 / PDF pp.233–234。三个子图均为低通；判别时分别令 `ω→0`（电容开路）与 `ω→∞`（电容短路）。

| 子图 | `ω→0` | `ω→∞` | 类型与通带增益 |
|---|---|---|---|
| (a) 缓冲 RC | 两电容开路，跟随器输出 `u_o=u_i` | 两电容短路，输出趋零 | 低通，`A₀=1` |
| (b) 反相放大加频率网络 | 电容开路，`R₁` 与反馈 `R₃` 决定反相比例 | 电容短路，输出趋零 | 低通，`A₀=−R₃/R₁` |
| (c) 两级组合 | 输入电容开路，第一极输出趋零；第二级得到 `u_o=−u_i` | 第一极变为反相比例级；按题设 `R₁=R₂`、`R₄=R₅=R₆`，第二级相消至零 | 低通，`A₀=−1` |

该题的要点不是先认图形像哪种滤波器，而是先计算两端频率极限，再求通带增益。它没有给出完整传递函数，因此本重构不声称得到了各自的极点或 −3 dB 频率。

## AP 例 6.3.13：乘法器反馈的压控低通

**原书位置：**图 6.3.14，印刷 pp.225–226 / PDF pp.234–235。反相求和节点 KCL 为

`U_i/R_1=−U_o/R_2−jωC U_o1`，乘法器满足 `U_o=kU_o1U_REF`。代入得到

`A_u(jω)=−(R_2/R_1)/[1+jωR_2C/(kU_REF)]`，`A_up=−R_2/R_1`，`f_p=kU_REF/(2πR_2C)`。

题设 `R_1=10 kΩ`、`R_2=100 kΩ`、`C=0.01 μF`、`k=0.1 V⁻¹`，故 `A_up=−10`；`U_REF=3–6 V` 时 `f_p≈47.7–95.5 Hz`。这是理想一阶低通，参考电压线性调截止频率而不改变通带增益。实际还要检查乘法器与运放动态范围及反馈稳定性。推导和数值复核见[例 6.3.13–6.3.15 审计](../sources/a06-ap-examples-13-15-audit.md)。

## AP 例 6.3.14：负载电流与输入电压成比例

**原书位置：**图 6.3.15，印刷 pp.226–227 / PDF pp.235–236。题设 `R_2=R_3=R_4=R_7=R`、`R_5=2R`。第一级得 `u_o1=2u_i−u_o`；第二级得 `u_o2=−2u_o1=−4u_i+2u_o`。按图中向下的负载电流参考方向列节点 KCL：

`i_L=(u_o2−u_o)/R_7−(u_o−u_i)/R_3=−3u_i/R`。

理想状态下 `i_L` 不随 `R_L` 变化，但正 `u_i` 对应的实际电流方向与图示箭头相反。恒流范围由运放电源余量、负载电压需求和输出电流能力决定；超出余量时运放饱和，恒流关系失效。完整节点复算见[专项审计](../sources/a06-ap-examples-13-15-audit.md)。

## AP 例 6.3.15：自举降低输入等效电容

**原书位置：**图 6.3.16，印刷 pp.227–228 / PDF pp.236–237。两级理想跟随器使 `u_o1=u_i`、`u_o=[R_2/(R_1+R_2)]u_i`。跨接在输入与输出之间的电容电流为 `i_i=jωC(u_i−u_o)`，所以输入等效电容

`C'=[R_1/(R_1+R_2)]C`。

当 `C=0.05 μF`、电位器滑片使 `R_1` 从 0 变化至 `R_1+R_2`，`C'` 理想范围为 `0–0.05 μF`。这改变的是从输入端看见的等效值，不是电容本体；实际范围还受跟随器带宽、相位差、输出负载与寄生电容影响。等效阻抗和密勒定理两种核验见[专项审计](../sources/a06-ap-examples-13-15-audit.md)。
