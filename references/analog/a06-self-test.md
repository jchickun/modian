# A06 章末自测 T6.3：答案与推导

**原题来源：**AT《模拟电子技术基础（第六版）》印刷 p.304/PDF p.336；AP《模拟电子技术基础学习辅导与习题解答（第六版）》印刷 pp.228–229/PDF pp.237–238。两书自测题和图 T6.3 的选项、题干、元件标号及电路连接已逐项对照；AT 自身答案二维码未取回，以下将 AP 可见解答与独立推导分开说明。页图证据见[AT/AP 自测审计](../sources/a06-at-ap-t63-selftest-audit.md)。

## 一、运算电路选择

AP 页印出的答案序列为 `C、F、E、A、C、D`：

1. 正弦波移相 `+90°`：AP 答案为 C（积分器）。按常用 `e^{jωt}` 相量约定，积分器相移 `−90°`、微分器相移 `+90°`，故应选 D。原题未定义移相正负约定，保留 AP 答案并标为约定冲突；若按该标准相量约定解题，应使用 D。
2. 正弦波倍频：F（乘方/平方）。平方后除二倍频分量外还含直流分量；若只要纯二倍频，需再滤除直流。
3. 正弦波叠加直流量：E（加法/求和）。
4. 实现 `A_u=−100`：A（反相比例）。
5. 方波转三角波：C（积分）。
6. 方波转尖顶波：D（微分）；理想模型在跳变处给冲激，实际输出受带宽、噪声和转换速率限制。

## 二、滤波电路选择

AP 答案为：`(1) 带阻 (BEF)，(2) 带通 (BPF)，(3) 低通 (LPF)，(4) 有源滤波器`。

50 Hz 干扰需由带阻/陷波压制；保留 10–12 kHz 窄带信号需带通；提取低频信号用低通；需要低输出阻抗、减轻负载变化对滤波特性的影响时采用有源结构。实际有源滤波器仍受输出摆幅、电流和带宽限制。

## 三、图 T6.3(a)：加权求和后积分

A1 同相端由 `R_3`、`R_4` 分压：

`u_+ = [R_4/(R_3+R_4)]u_i3`。

反相端节点 KCL 给出

`u_o1 = −R_f(u_i1/R_1 + u_i2/R_2) + [1+R_f/(R_1∥R_2)]u_+`。

代入分压式后，A2 是反相积分器，因此

`u_o(t) = −(1/RC)∫u_o1(t)dt + K`，

其中 `K` 由反馈电容的初始电压决定。该电路是加权求和与积分的级联，不是乘法器电路。

## 四、图 T6.3(b)：乘法器平方反馈开方

AT 与 AP 原图的乘法器两个输入都接到 `u_o`，所以

`u'_o = k u_o²`。

A2 反相级与 A1 求和节点分别给出

`u_o2 = −(R_3/R_4)u'_o`，

`u_o2 = −(R_2/R_1)u_i`。

联立得

`u_o² = [R_2R_4/(kR_1R_3)]u_i`。

对题图所示 `u_i>0、k>0`，平方根实数；原图二极管极性选择 AP 所列的负根：

`u_o = −√{[R_2R_4/(kR_1R_3)]u_i}`。

当 `u_i<0` 时取 `k<0`，并将二极管反接，使平方根输入仍为非负且环路保持正确极性。除输入/系数符号条件外，还需避免乘法器和运放输出饱和。这里的平方根关系与 AP 可见解答一致；AT 二维码答案仍未取回。

## 使用边界

- AP 对第一个相移小题给“积分器”，但未说明相量正负约定；使用时应显式写出约定，不能把 AP 答案无条件推广为 `e^{jωt}` 下的结论。
- AT/AP T6.3 的题图和问题相符；AP 的文字答案用于交叉校验，不等于已取得 AT 二维码答案。
- 题目未给具体阻容值，不计算截止频率、积分斜率数值或实际器件误差。
