# A00 第 0 章：信号、电子系统与工程方法

**来源：** AT《模拟电子技术基础》第六版第 0 章，现有扫描为 PDF pp.35–41（印刷 pp.1–7）；印刷 p.8 未包含在扫描件中，内容/是否空白尚不能确认。本书没有对应的 AP 习题章。页码核对见[A00 页码与 EDA 资料审计](../sources/a00-at-introduction-audit.md)及[来源目录](../sources/catalog.md)。

## 0.1 电信号：消息如何变成可处理的量

信号是承载消息的物理量；信息是消息中对接收者有用的新内容。温度、声音、压力等非电量通常先由传感器转换成电压或电流。对电路分析，可把信号写成时间函数 `u(t)` 或 `i(t)`。

- **模拟信号**：时间连续、幅值连续。多数传感器输出属于这一类。
- **数字信号**：时间和幅值均按离散值描述。模拟信号送入计算机前要经过 A/D；数字结果驱动模拟负载前常经过 D/A。
- 不要把“采样”与“量化”混为一谈：采样使时间离散，量化使幅值离散；书中用“数字信号”概括二者。

电路看到的是电压、电流及其频率、幅值和噪声，而不是抽象的信息本身。分析接口时要追问传感器输出是否够大、噪声是否可控、负载是否会改变信号。

## 0.2 电子系统：从采集到执行

原书的系统框图可压缩为：

`传感器/信号源 → 提取 → 预处理 → 加工 → 功率驱动 → 执行机构/负载`

预处理负责隔离、滤波、阻抗变换、抑制干扰和初级放大；加工可包含运算、转换、比较、采样保持等。若加入数字处理，常见链路是：

`模拟预处理 → A/D → 计算机/数字系统 → D/A → 功率驱动 → 负载`

常见模拟功能块包括：放大（电压、电流或功率）、滤波、运算（加减乘除、积分微分等）、信号转换、信号发生和直流供电。AT p.4 以把 220 V、50 Hz 交流转换成不同输出电压和电流的直流电源为系统功能示例；这是教材中的功能说明，不是市电电源的设计参数。放大是许多模拟功能级的基础，但整机性能取决于各级连接后的接口和负载。

设计不能只盯单一指标。按原书的原则，至少同时检查功能与性能、可靠性、电磁兼容性、可测性和造价：满足指标后优先控制复杂度；布置测试点并考虑故障诊断；识别干扰源及耦合路径，按需要采取隔离、屏蔽、接地、滤波、去耦；一般先选能满足要求的通用器件，性能不够再换专用器件。各项指标之间需要权衡。

## 0.3 模拟电路的工程学习法

本章给出的不是“背一套精确公式”，而是以下工作顺序：

1. **先定性识别。** 从结构和器件连接判断功能、信号路径、偏置与可能的限制。
2. **再做定量估算。** 明确估算目标、工作条件、忽略了哪些参数及其理由；器件离散性和温度影响使很多“精确数值”并不精确。
3. **按问题选模型。** 直流偏置、小信号增量、频率响应、大信号摆幅各自需要不同模型，不能把一个等效模型用于所有问题。
4. **检查取舍和边界。** 增益、带宽、阻抗、噪声、失真、功耗、成本等会互相牵制；所谓“最好”必须相对于应用约束。
5. **走通理论、仿真、硬件。** 先用等效模型分析，再用器件模型仿真，最后搭建、测量和调试。实测中还会出现器差、温漂、寄生参数、布线与干扰。

仿真能检查模型和电路行为，不能替代对工作区、初始条件、器件参数、负载及测量设置的核对。

## 0.4 EDA：按问题选分析

原书介绍 SPICE、PSpice 和 Multisim，并列举直流工作点、直流转移特性、直流小信号传递函数、交流小信号、交流噪声、瞬态、傅里叶、直流灵敏度、温度、最坏情况和蒙特卡罗等模拟电路分析。按问题选择分析类型，不要把不同分析所得的模型条件混为一谈。

| 想回答的问题 | 适合的分析 |
|---|---|
| 偏置点是否落在预期工作区 | DC operating point |
| 输入电压/参数变化时输出如何变化 | DC sweep / parameter sweep |
| 小信号增益和相位如何随频率变化 | AC small-signal sweep |
| 小信号噪声随频率如何分布、各器件贡献多大 | Noise analysis |
| 波形、削顶、启动或开关过程如何变化 | transient |
| 周期波形包含哪些谐波分量 | Fourier analysis |
| 参数微变、温度及容差统计会不会造成越界 | sensitivity / temperature / worst-case / Monte Carlo |

做仿真时先选与问题对应的分析类型，再明确扫描变量、初始条件、输出节点和量纲；结果出来后，将数值与手算、器件工作区和电源/负载边界对照。NI 的[Multisim 分析手册](https://www.ni.com/docs/en-US/bundle/multisim/page/topics/analyses.html)列出当前分析设置和结果查看方式；瞬态分析还依赖初始条件与时间步长，详见[NI 瞬态分析说明](https://www.ni.com/docs/en-US/bundle/multisim/page/topics/fundamental-analysis-transient-analysis.html)。

**原书中的历史版本记录（AT pp.6–7）：** AT 记载 SPICE 于 1972 年研制、1975 年推出实用化版本；加州大学伯克利分校的校史独立确认 1972 年由 Donald O. Pederson 团队开发 SPICE，伯克利另有 1975 年 SPICE2 技术报告。AT 所称“1988 年被定为美国国家工业标准”在本次查阅的伯克利公开一手资料中未获独立佐证，因此只保留为原书说法，不把它写成已核实史实。书中脚注列 PSpice 16.3、Multisim 8（2005 年推出）及 Multisim 14.0；这些是原书记录的版本信息，不代表当前版本。AT p.7 声称 Multisim 当时含 18 种虚拟仪器；本技能只保留与模电测量直接相关的万用表、信号发生器、示波器、频谱分析仪、网络分析仪、失真分析仪、频率计、波特图仪和瓦特表，不扩展其余仪器类别。详细页图和来源边界见[A00 审计](../sources/a00-at-introduction-audit.md)。
