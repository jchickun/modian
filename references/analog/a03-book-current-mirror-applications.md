# A03 原题重构：AP 例 3.3.10–3.3.13

**来源：** AP《模拟电子技术基础学习辅导与习题解答（第六版）》印刷 pp.109–114 / PDF pp.118–123。原页逐页审计和有限 β 复算见[AP A03 例题 3.3.10–3.3.13 审计](../sources/a03-ap-examples-10-13-audit.md)。依据原题文字、图 3.3.9–3.3.13 和原解重构；不复制原书电路图。以下方程保留原题端口/箭头方向。带“近似”的式子须满足题设器件匹配、理想电流镜或小信号条件。

## 例 3.3.10：带射极输出管的多路镜像电流源

题设：`V_CC=12 V`，电源为 `±12 V`，各管匹配且 `U_BE=0.7 V`，基准电阻 `R=113 kΩ`。`T_0` 为基准管，`T_1、T_2` 为镜像输出管；`T_3` 作射极输出级，向三只镜像管的基极供电。

先求基准支路：

`I_R=(2V_CC−U_BE3−U_BE0)/R=(24−0.7−0.7)/113 kΩ=0.2 mA`。

有 `T_3` 时，三只镜像管的总基极电流为 `3I_C/β`，由 `T_3` 提供的电流是其射极电流，故 `I_B3=3I_C/[β(1+β)]`。在基准节点列 KCL：

`I_R=I_C+I_B3=I_C[1+3/{β(1+β)}]`

因此

`I_C1=I_C2=I_C0={β(1+β)/[β(1+β)+3]} I_R`。

当 `β(1+β)≫3` 时，输出电流接近 `I_R`。AP 用 `β=10` 演示有限 β：比例为 `110/113≈0.973`；若 `I_R=0.2 mA`，输出约 `0.195 mA`。若去掉 `T_3`，三只基极电流直接从基准支路分流，则 `I_C=β/(β+3)·I_R`；同取 `β=10` 时仅约 `0.769I_R`。若要与含 `T_3` 的情况在相同 `I_R=0.2 mA` 下比较，因参考支路少一个 `V_BE` 压降，电阻应从 `113 kΩ` 调为 `116.5 kΩ`。因此 `T_3` 的作用是隔离基准支路、减小输出电流对有限 β 的敏感度；它不能消除 Early 效应、失配或温漂。

## 例 3.3.11：镜像电流作差与电流—电压转换

题设：`T_1–T_3` 匹配，`β≫2`；两输入支路电流按原图箭头记为 `i_11`、`i_12`，输出级为 `T_3` 共射级，集电极接 `R_C`。

1. `T_1、T_2` 构成电流镜，故 `i_C2≈i_C1≈i_12`。
2. 在 `T_3` 基极节点列 KCL：`i_B3=i_11−i_C2≈i_11−i_12`。
3. 小信号下 `Δi_C3≈βΔi_B3`，而共射集电极输出 `Δu_o=−R_CΔi_C3`。

所以相对于差值输入电流的跨阻为

`A_ui=Δu_o/Δ(i_11−i_12)≈−βR_C`。

负号来自共射反相；量纲为 Ω。这是电流差到电压的跨阻，不是无量纲电压增益。有限 β 时镜像误差、基极电流和器件失配都会使近似偏离。

## 例 3.3.12：差分输入、有源负载和共射中间级

题设参数：`V_CC=12 V`、`V_EE=6 V`，各管理想匹配，`U_BE≈0.7 V`、`r_be≈1 kΩ`、`β=100`；`I_C1=0.2 mA`、`I_C9=1.5 mA`。输入 `u_i=0` 时输出静态值为零。题目要求识别级数/接法，并估算 `R_1、R_3、R_i、R_o` 与 `R_L=10 kΩ` 时的电压增益。

### 拓扑与偏置电阻

- 第一级是 `T_1、T_2` 差分输入，`T_3、T_4` 镜像有源负载，将差分电流转为单端信号；`T_5、T_6、T_7` 构成第一级偏置电流源。
- 第二级以 `T_8` 共射放大，`T_9` 电流源作有源负载。理想电流源负载提供很大的电压增益；实际增益受有限输出电阻、摆幅和负载影响。

由偏置支路，`I_C5=I_C6≈2I_C1=0.4 mA`，故

`R_1≈(V_CC+V_EE−U_BE7−U_BE6)/I_C5=(12+6−0.7−0.7)/0.4 mA≈41.5 kΩ`。

图示电平关系给出 `U_R3=U_BE7+U_BE6−U_BE9≈0.7 V`。又 `I_R3≈I_E9≈I_C9=1.5 mA`，所以按给定数值直接计算：

`R_3≈0.7 V/1.5 mA≈467 Ω`。

**原书数值差异：** AP 印为约 `476 Ω`；用同页给出的 `0.7 V` 和 `1.5 mA` 相除得到约 `467 Ω`。`476 Ω` 与题面数值不完全相符，可能来自未写明的中间近似，现有原页不足以确认其来源，故不静默照抄。

### 输入、输出电阻与增益

差分输入端口的近似电阻为 `R_i≈2r_be≈2 kΩ`。AP 的理想晶体管模型取集电极—发射极输出电阻无穷大，因此输出电阻也按理想模型记为 `R_o→∞`；真实器件的有限 `r_o`、偏置网络和负载会使其有限。

差模信号经第一级镜像负载后，`T_8` 基极电流变化近似为 `Δi_B8≈2βΔi_B1`；第二级电流源负载再把它转换为 `Δi_L≈βΔi_B8≈2β²Δi_B1`。输入端 `Δu_i≈2r_beΔi_B1`，负载输出 `Δu_o≈−Δi_LR_L`，于是

`A_u≈−β²R_L/r_be=−100²×10 kΩ/1 kΩ≈−1.0×10^5`。

该结果属于题设理想模型下的中频小信号估算；不能据此推断大信号摆幅、闭环稳定性或实物运放的负载驱动能力。

## 例 3.3.13：简化运放结构与极性读图

本题去掉了偏置网络，考查结构识别。原题选择结果为 **(1) B，(2) A，(3) C，(4) A，(5) C，(6) C，(7) A，(8) B**。

| 问 | 结论 | 原图判读依据 |
|---|---|---|
| (1) 输入级接法 | 共集—共基 | 信号加在 `T_1、T_2` 基极，前级发射极驱动 `T_3、T_4`；该组合可扩展带宽。 |
| (2) 采用该输入级的目的 | 展宽频带 | 共基级减小高频米勒效应；不是为了提高输入电阻或电流增益。 |
| (3) `T_5、T_6` 的作用 | 增大差模增益 | 镜像有源负载把差分级单端输出的差模增益提高。 |
| (4) 中间级接法 | 共射 | 中间级承担主要电压放大。 |
| (5) 中间级放大管 | `T_7、T_8` 复合管 | 按基极、集电极和发射极连接关系识别复合放大管。 |
| (6) 输出级 | 互补输出级 | `T_9、T_10` 的基极为输入、发射极相连处为输出。 |
| (7) `D_1、D_2` 作用 | 消除交越失真 | 二极管提供互补输出管静态导通所需的偏置电压；实际偏置还受温度跟踪影响。 |
| (8) `u_o` 与 `u_11` 相位 | 同相 | 按题设输入极性，`u_11` 为同相端，`u_12` 为反相端。 |

**使用边界：** 第 (8) 问的相位依赖图示输入/输出标记和差模极性；交换输入端或改变输出定义后，结论随之改变。结构题应沿器件端子和信号方向读图，不按元件在页面上的上下左右位置猜测。
