## 逐页核查与方法

| 印刷页 / PDF 页 | 原页重点 | 蒸馏方法与边界 |
|---|---|---|
| 160–161 / 169–170 | §5.2.1 有无反馈；§5.2.2 反馈量仅取决于输出量 | 找输出变化能否经某条完整路径影响输入，路径可经过发射极电阻等间接元件。电阻上的实际电压/电流可能同时含输入源作用和输出作用；反馈量仅是输出造成的分量。用叠加法把两部分写开，求反馈量时令输入源的独立作用为零。 |
| 162 / 171 | 电压、电流反馈量的叠加分解；§5.2.3 端口取样 | 输出量分量可能与电阻实际电压的参考极性相反，必须按定义分离而非直接抄电阻标号。将输出电压置零作小信号端口测试：反馈分量随之为零是电压取样；仍存在则是电流取样。分立级的输出电流常是输出晶体管支路电流，不必等于负载电流。 |
| 163 / 172 | 电流反馈的支路边界；§5.2.4 反馈网络组成 | 电流负反馈稳定它取样的那条支路电流，不自动稳定负载电流。反馈网络包含输出量到反馈量之间所有影响分流、分压的元件，不只是那只直接连接输入和输出的电阻。按题图把路径画全，再独立源归零、由输出变量单独驱动求 `F=x_f/x_o`。 |
| 164 / 173 | 反馈系数求法；§5.2.5 两路级间反馈和自举 | 多反馈路径逐条判极性与目的。AP 图 5.2.4 中主路径是串联负反馈，另一条是并联正反馈；两者的极性不同，但都帮助提高输入电阻。拆开分析每条路径，最后再看其组合效果，不把两路合并成一个等效反馈元件。 |
| 164–165 / 173–174 | §5.2.6 滞后补偿电容选择 | 加滞后补偿电容可抑制高频自激，但会压窄带宽。先找各级自身上限频率，优先在上限最低的一级补偿，以减少对整机带宽的额外损失。单管共射近似 `f_H≈1/(2πR C_π′)`，其中 `C_π′≈C_π+(1+g_mR_L′)C_μ`；故 `R C_π′` 较大的级往往是候选。中间级因增益较高常成为候选，但若给定具体参数，应计算后选择，不能只按“中间级”固定判断。 |

原页对 §5.2.6 的适用模型还有限定：直接耦合放大电路引入交流负反馈且反馈网络为纯电阻时，教材将附加相移归因于放大级，并按高频自激选择补偿点。若电路含耦合/旁路电容或反馈网络有显著电抗，低频稳定性也要单独检查；本节高频选点规则不能代替全频段环路分析。

## 独立核对的典型表达式

- 电压并联例中，`R_2` 的实际电流可写为 `i_R2=u_N/R_2−u_o/R_2`；第一项由输入端作用产生，第二项才是输出引起的反馈电流。因此该例 `i_f=−u_o/R_2`，而非整条实际电流。
- 电压串联例中，`R_3` 的实际电压分为输入级电流项与输出分压项；令输入级作用为零后得到 `u_f=[R_3/(R_6+R_3)]u_o`。输出反相的另一图例中同一支路实际压降与反馈分量符号可相反，不能用实际电压箭头代替反馈极性。
- AP 图 5.2.3(a) 反馈网络示例给 `F=U_f/I_o=−R_4R_8/(R_4+R_5+R_8)`，单位为 Ω；图 5.2.3(b) 给 `F=I_f/I_o=−R_2/(R_1+R_2)`，无量纲。两式均按原图参考方向；换方向要同步换符号。

## 解题时的分步顺序

1. 分别画直流和目标频段的交流路径，找到输出到输入的全部潜在通路。
2. 固定输入、逐级跟踪瞬时极性；每条回路单独定正负反馈和作用目的。
3. 定义反馈输出量与输入量，按叠加分离“输入源造成的量”和“输出造成的量”。
4. 通过输出端口变量测试电压/电流取样，按输入端净变量差别判断串联/并联混合。
5. 画出完整反馈网络并求 `F`；用题目给定的源、负载和网络加载核对单位与符号。
6. 若需消振，先比较各级上限频率和 `R C_π′`，再选补偿节点并复核带宽变化。
