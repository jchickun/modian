## P2.17：栅极偏置与失真调节

- 图示为 N 沟道 FET 共源电路；\(R_D\) 接漏极，\(R_S\) 接源极并由 \(C_S\) 交流旁路；\(C_1,C_2\) 为输入、输出耦合电容。
- \(R_1\) 从 \(V_{DD}\) 接分压节点，\(R_2\) 从该节点接地，\(R_3\) 将分压节点接至栅极。因 FET 栅极直流电流近似为零，\(R_3\) 上直流压降近似为零：
  \[
  U_{GQ}\approx V_{DD}\frac{R_2}{R_1+R_2},\qquad
  U_{GSQ}=U_{GQ}-I_{DQ}R_S,\qquad
  V_{D,Q}=V_{DD}-I_{DQ}R_D.
  \]
- 按原书在本题工作区给出的方向，底部削顶可增大 \(R_1,R_S\) 或减小 \(R_2,R_D\)；顶部削顶可减小 \(R_1,R_S\) 或增大 \(R_2\)。它们通过改变 \(I_{DQ}\)、\(g_m\) 或漏极静态电压移动 Q 点；这不是在所有器件与偏置网络下都成立的无条件口诀。
- 原书给出的增益方向为：减小 \(R_1,R_S\)、增大 \(R_2\) 以提高静态电流和跨导，或增大 \(R_D\)。当 \(C_S\) 中频充分旁路、忽略 \(r_o\) 时，栅极到输出增益约为 \(-g_m(R_D\parallel R_L)\)。增大 \(R_D\) 也改变直流 Q 点，必须重新检查工作区和摆幅。
- 忽略栅极漏电时，输入电阻近似为 \(R_i=R_3+(R_1\parallel R_2)\)。若源内阻为 \(R_{\rm src}\)，源到输入端的分压系数为 \(R_i/(R_{\rm src}+R_i)\)；题目未给源内阻，未虚构系统级数值。

## P2.18：复合管逐图判定

原书要求先假设施加合适电压，再检查每只管是否有对应的控制条件和主电流通路。逐图依页上符号和连线记录：

| 图 | 结论 | 类型与上 / 中 / 下端子或失败原因 |
|---|---|---|
| (a) | 不可 | \(T_1\) 没有集电极电流通路 |
| (b) | 不可 | \(T_2\) 为 MOS 管，绝缘栅使 \(T_1\) 的集电极—发射极通路中断 |
| (c) | 可 | NPN；集电极 / 基极 / 发射极 |
| (d) | 不可 | \(T_1\) 没有集电极电流通路 |
| (e) | 不可 | \(T_2\) 的栅源绝缘使 \(T_1\) 的漏极—源极通路中断 |
| (f) | 可 | PNP；发射极 / 基极 / 集电极 |
| (g) | 可 | NPN；集电极 / 基极 / 发射极 |

上述端子名针对图中上下端口及中间控制端，不能脱离原图箭头、器件极性和连线套用。
