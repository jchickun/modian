## 独立推导

小信号下令 FET 的栅源电压为 `u_{gs1}`。FET 源极电流近似等于其漏极电流，也等于驱动 BJT 的基极电流：

```text
i_b2 ≈ i_s1 ≈ i_d1 = g_m1 u_gs1
u_be2 = r_be2 i_b2 = g_m1 r_be2 u_gs1
u_gs = u_gs1 + u_be2 = (1 + g_m1 r_be2) u_gs1
i_d = i_d1 + i_c2 ≈ (1 + β_2) g_m1 u_gs1
```

因此

```text
g_m,eq = i_d/u_gs = (1 + β_2)g_m1/(1 + g_m1 r_be2)
```

当 `β_2≫1` 时，才可将分子近似为 `β_2g_{m1}`；不能据此删掉分母。量纲也一致：`g_{m1}r_{be2}` 无量纲，`g_{m,eq}` 的单位为西门子。

## 使用边界

- 推导采用 Q 点附近的小信号模型，假设 FET 工作在恒流区、BJT 工作在正向放大区，并忽略两管输出电阻、结电容和频率效应。
- 只有当 `g_{m1}r_{be2}≪1` 时，才可再把分母约成 1；`β_2≫1` 本身不足以支持这个简化。
- 自构数值敏感性示范 `g_{m1}=2 mS`、`r_{be2}=1.5 kΩ`、`β_2=100` 得 `g_{m1}r_{be2}=3`、`g_{m,eq}=50.5 mS`；漏分母会算成 `202 mS`，高估 4 倍。该数值仅说明公式敏感性，不是原书题目。
