## 例 2.3.1：Q 点迁移

- `Q_1`、`Q_2` 在同一输出特性曲线上，故输入偏置未变；两点的负载线不同且 `Q_2` 线更陡，由斜率 `−1/R_C` 可判 `R_C` 减小。
- `Q_2`、`Q_3` 在同一负载线上，故 `V_CC`、`R_C` 不变；基极电流从图示 `10 μA` 到 `20 μA`，表明输入偏置改变。单凭图不能区分 `R_B` 变小、`V_BB` 增大或二者同时变化。
- `Q_3`、`Q_4` 位于同一输出特性曲线上，输入偏置未变；负载线平行，故 `R_C` 不变而 `V_CC` 增大。
- `Q_2` 最靠近截止区，`Q_3` 最靠近饱和区，`Q_4` 的双向摆幅余量最大。图示 `Q_4` 为 `U_CEQ≈6 V`，题解按 `U_CES=0.7 V` 得最大输出有效值 `(6−0.7)/√2≈3.75 V`；这是有效值，峰值约 `5.3 V`。
- 图示 Q4 负载线横轴截距 `12 V`、纵轴截距约 `4 mA`，故 `V_CC=12 V`、`R_C=12/4 mA=3 kΩ`。这些是读图值，不增加有效数字。

## 例 2.3.2：固定偏置与端口定义

题给 `V_BB=1 V`、`R_B=24 kΩ`、`V_CC=12 V`、`R_C=5.1 kΩ`、`r'_{bb}=100 Ω`、`β=100`、`U_{BEQ}=0.7 V`。按原书 `U_T=26 mV`：

| 量 | 独立复算 | 原书/重构口径 |
|---|---:|---|
| `I_BQ` | `(1−0.7)/24 kΩ = 12.5 μA` | `12.5 μA` |
| `I_CQ` | `βI_BQ = 1.25 mA` | `1.25 mA` |
| `U_CEQ` | `12−1.25×5.1 = 5.625 V` | `≈5.63 V`，处于放大区 |
| `r_be` | `100 Ω+100×26 mV/1.25 mA = 2.18 kΩ` | `≈2.2 kΩ` |
| `A_u` | `−100×5.1/(24+2.18) = −19.48` | `≈−19.5` |
| `R_i` | `R_B+r_be≈26.18 kΩ` | `≈26.2 kΩ`，含串联 `R_B` |
| `R_o` | `R_C=5.1 kΩ` | 忽略晶体管输出电阻 |

原题的输入端口位于 `R_B` 前，故书中 `R_i=R_B+r_be` 是源侧总输入串联电阻；若端口设在基极，晶体管自身小信号输入电阻为 `r_be`。`R_B` 短路时失去偏置支路限流，教材定性判断晶体管可能烧坏；题目未给源内阻，不能求唯一短路电流。

## 例 2.3.3：阻容耦合与 `C_2` 短路

题给 `V_CC=12 V`、`R_B=510 kΩ`、`R_C=R_L=3 kΩ`、`r'_{bb}=150 Ω`、`β=80`、`U_{BEQ}=0.7 V`，取 `U_T=26 mV`：

| 量 | 独立复算 | 说明 |
|---|---:|---|
| `I_BQ` | `(12−0.7)/510 kΩ = 22.16 μA` | 输入偏置回路 |
| `I_CQ` | `80×22.16 μA = 1.773 mA` | 固定偏置模型 |
| `U_CEQ` | `12−1.773×3 = 6.68 V` | `R_L` 经耦合电容隔直 |
| `r_be` | `150 Ω+80×26 mV/1.77255 mA ≈1.32345 kΩ` | 原书先取 `I_CQ≈1.77 mA`，得 `≈1.325 kΩ` |
| `R'_L` | `R_C∥R_L=1.5 kΩ` | 中频交流负载 |
| `A_u` | `−80×1.5/1.32345≈−90.67` | 原书约 `−90`，含参数舍入 |
| `R_i` | `R_B∥r_be≈1.32 kΩ` | 原书近似 `1.33 kΩ` |
| `R_o` | `R_C=3 kΩ` | 移除外接负载、忽略 `r_o` |
| `A_{us}` | `A_uR_i/(R_s+R_i)≈−36.05`，`R_s=2 kΩ` | 源侧增益，含输入分压；原书约 `−36` |

若 `C_2` 短路，负载进入直流回路而输入回路不变，所以 `I_BQ`、`I_CQ` 近似不变。输出端戴维南等效为 `V'_CC=R_LV_CC/(R_C+R_L)=6 V`、`R'_C=R_C∥R_L=1.5 kΩ`，于是 `U'_{CEQ}=6−1.773×1.5≈3.34 V`。Q 点移向饱和侧，最大不失真摆幅减小。中频交流下耦合电容本来就是短路，因此等效小信号增益和端口电阻不变；低频电容阻抗不可忽略时该结论不适用。

## 模型边界

- 使用题给 `U_{BEQ}=0.7 V`、固定 `β` 和低频 h 参数近似；`U_T=26 mV` 是计算条件。温度、电流区间及实际器件参数变化未建模。
- `R_o=R_C` 假设 h 参数模型忽略晶体管输出电导；实际输出电阻有限时需按器件模型补入。
- 增益要区分放大器端口增益与信号源到输出的总增益；例 2.3.2 的 `R_i` 包含串联 `R_B`，例 2.3.3 的 `A_{us}` 另计 `R_s` 分压。
