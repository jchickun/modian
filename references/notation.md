# 模拟电子术语与符号约定

## 量与端口

教材符号可能区分直流静态量、大写/小写交流量、瞬时值、有效值和复数相量。题目采用的约定优先；遇到大小写或下标不明时，先写出量的定义，不凭字母外观推断。

| 符号 | 使用提醒 |
|---|---|
| `V_BE`, `I_C`, `U_CEQ` | 常表示直流偏置量；以下标 `Q` 标明静态工作点 |
| `v_be`, `i_c`, `u_ce` | 常表示交流增量或瞬时量，需与静态量区分 |
| `A_v` | 电压增益可能带符号；负号通常表示反相，必须说明输入参考端 |
| `β_DC` | `I_CQ/I_BQ`，直流工作点比值 |
| `β_ac` | Q 点附近固定条件下的小信号增量斜率，不自动等于 `β_DC` |
| `β_f` | 可用于反馈系数，避免与 BJT 电流增益混淆 |
| `V_CC` | 说明是单轨幅值还是正负电源轨间总电压 |
| `V_pp`, `V_pk`, `V_rms` | 峰峰值、峰值、有效值；正弦量满足 `V_pp=2V_pk`、`V_rms=V_pk/√2` |
| `R_i`, `R_o` | 标明观察端口、负载状态，以及独立输入源是否置零 |

## 同名概念的边界

- BJT 的“饱和区”表示发射结和集电结均正偏的状态，常作为开关导通区；MOSFET 的“饱和区”通常指沟道夹断后的放大区。判断工作区必须先说明器件种类。
- “截止频率”在频响章节通常指相对中频增益降至 `1/√2` 的频率；若题目另设幅值或相位门限，按题意。
- “输出电阻”是从指定输出端向电路内部看的小信号等效阻抗，不是负载电阻。
